What do these words mean?

Cracked
The copy protection was removed, so the game runs without a bought copy.
Denuvo
The strongest and most common anti-piracy protection. Games with it often stay uncracked for months or never get cracked at all, so a Denuvo crack is big news.
Hypervisor workaround
A way to get around Denuvo without really removing it. You have to turn off Windows security features (such as virtualization-based security and driver signature checks) and run a low-level driver. Treat it as risky, not as a real crack.
Scene group
An organised release group (RUNE, TENOKE, Razor1911…). They are usually the first to put out a crack.
Repack
An existing crack recompressed by someone else (ElAmigos, FitGirl, DODI…) so it's smaller to download and easier to install. Repacks don't crack anything new.
DRM-free / GOG
GOG is a store that sells games without copy protection. Once a game is on GOG, a copy without protection exists by design.
Update
A newer game version, packaged to work with an existing crack.
Protection removed
The publisher took Denuvo out of the official game themselves, often a few years after launch.
